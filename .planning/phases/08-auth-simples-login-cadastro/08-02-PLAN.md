<threat_model>
Trust boundaries:
- Client validation is UX only; server remains authority.
- Auth cookie is HTTP-only; frontend only knows current user from `/api/auth/me`.

STRIDE register:
- S-01 spoofed UI state: mitigate by loading `/api/auth/me` on boot and clearing state on 401/logout.
- T-01 tampered form values: mitigate server validation in Plan 01.
- I-01 token exposure: do not store tokens in localStorage/sessionStorage.
- D-01 repeated submit spam: disable submit while pending and rely on API rate limits.

Block on: high.
</threat_model>
